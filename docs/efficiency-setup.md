## کنترل کیفیت

در استخراج اولیه، HTML، CSS و JavaScript با خروجی قبلی byte-for-byte برابر بودند. پس از افزودن fallback مسیر برای صفحات بعدی، HTML و CSS همچنان برابر ماندند. هیچ بازطراحی ظاهری در این مرحله انجام نشد.

ده کنترل واقعی مرورگر روی خروجی ماژولار پاس شدند: هم‌عرضی هدر و محتوا، حداقل تایپوگرافی و قیمت، ویدیو ۱۲ثانیه‌ای، بازشدن سبد، جای سبد، پروفایل، تب مشخصات، فیلتر نظرات و باز/بسته‌شدن ادامه مقاله.

بررسی محلی نیز RTL، شناسه‌های یکتا، فایل‌های دارایی، نمادهای Phosphor، هر ۹ وزن فونت، حداقل اندازه ۱۲ و نقاط اتصال رابط را کنترل می‌کند. ساخت صفحات بعدی در یک پوشه موقت آزمایش می‌شود.

## نتیجه اندازه‌گیری RTK

فرمان واقعی پروژه: `ls -lR src`

- خروجی معمولی: ۵۲۴۸ بایت
- خروجی RTK: ۱۳۷۹ بایت
- کاهش حجم همان خروجی: ۷۳.۷٪
- خطای مسیر ناموجود نیز با وضعیت ناموفق و نام مسیر حفظ شد.

این نتیجه، کاهش خروجی یک فرمان است؛ کاهش سهمیه کل یا نصف‌شدن مصرف کل اندازه‌گیری یا تضمین نشده است. مدل کوچک‌تر نشده و کنترل‌های کیفیت حذف نشده‌اند.

## استفاده از این پس

در همین پوشه پروژه کار کنید. برای صفحه جدید نام صفحه و مرجع همان صفحه را بدهید؛ لوگو، فونت و اجزای مشترک دوباره لازم نیست ارسال شوند، مگر تغییر کرده باشند. اصلاحات مرتبط را یک‌جا ارسال کنید. چت صفحه جدید می‌تواند کوتاه و مستقل باشد؛ مرجع مشترک در فایل‌ها محفوظ است.

عامل ابتدا تصمیم‌های کوتاه و فایل‌های مرتبط را می‌خواند، تغییر محدود می‌دهد، بررسی لازم را اجرا می‌کند و فقط هنگام تحویل بسته می‌سازد. معیار کیفیت ظاهر و تعامل‌ها حفظ می‌شود.
